# 🌱 FarmWise AI

FarmWise AI is an AI-powered agriculture platform that helps farmers detect crop diseases, analyze field conditions, access weather insights, and receive smart farming recommendations.

## ✨ Features

- 🌿 Crop Disease Detection
- 🤖 AI-powered Analysis
- 🌦️ Weather Insights
- 📍 Location-based Advisory
- 💡 Smart Treatment Recommendations
- 📱 Farmer-friendly Interface

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- AI/ML

## 🎯 Goal

To help farmers make better and faster farming decisions using Artificial Intelligence and real-time environmental information.
