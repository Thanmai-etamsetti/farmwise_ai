# 🌱 FarmWise AI

**FarmWise AI** is an AI-powered smart agriculture platform designed to help farmers make better and faster farming decisions. It provides crop disease detection, weather insights, field analysis, and smart recommendations using Artificial Intelligence and modern web technologies.

## 🚀 Features

* 🌿 **Crop Disease Detection** – Identify possible diseases from crop/leaf images.
* 🤖 **AI-Powered Analysis** – Analyze crop-related inputs and provide useful insights.
* 🌦️ **Weather Information** – Get weather conditions useful for farming decisions.
* 📍 **Location-Based Insights** – Provide information based on the selected location.
* 💡 **Smart Recommendations** – Suggest suitable treatments and preventive measures.
* 📱 **Responsive Design** – Works across desktop, tablet, and mobile devices.
* 🌾 **Farmer-Friendly Interface** – Simple and easy-to-understand design.

## 💻 How to Run the Project

### 1. Clone the Repository

Open your terminal or command prompt and run:

```bash
git clone https://github.com/your-username/farmwise-ai.git
```

Then move into the project folder:

```bash
cd farmwise-ai
```

### 2. Install Dependencies

If the project uses Node.js, install the required packages:

```bash
npm install
```

### 3. Configure Environment Variables

If the project uses API keys, create a `.env` or `.env.local` file in the root directory.

Example:

```env
WEATHER_API_KEY=your_api_key
AI_API_KEY=your_api_key
```

Replace the placeholder values with your actual API keys.

**Do not upload your API keys or `.env` files to GitHub.**

### 4. Start the Development Server

Run:

```bash
npm run dev
```

The terminal will show the local development URL.

For example:

```text
http://localhost:3000
```

Open this URL in your browser to access **FarmWise AI**.

## 🔧 Troubleshooting

If `npm install` doesn't work, make sure **Node.js and npm** are installed on your system.

Check the versions using:

```bash
node -v
npm -v
```

If the required dependencies are missing, run:

```bash
npm install
```

If the port is already in use, stop the other running application or use another available port.

## 🌾 How It Works

1. User opens the FarmWise AI platform.
2. User provides crop information or uploads a crop image.
3. The system processes the provided information.
4. AI analyzes the crop and environmental data.
5. Weather and location information are considered when required.
6. The platform provides possible disease information and recommendations.
7. The farmer can use these insights to take appropriate preventive or corrective action.
